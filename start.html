2 Auf dem Gerät ablegen

Damit BauPilot wie eine normale App startet (und die Daten sicher auf dem Gerät bleiben):

  1. Diese Seite in Safari öffnen (nicht in WhatsApp oder Mail).
  2. Unten bzw. oben auf das Symbol Teilen (Quadrat mit Pfeil) tippen.
  3. Zum Home-Bildschirm wählen, dann Hinzufügen.
  1. In Safari oben in der Menüleiste auf Ablage klicken.
  2. Zum Dock hinzufügen wählen, dann Hinzufügen.
  1. Rechts in der Adresszeile auf das Symbol Installieren (Monitor mit Pfeil) klicken.
  2. Installieren bestätigen. Fertig, BauPilot liegt im Programmordner/Dock.
  1. In Chrome oben rechts auf die drei Punkte tippen.
  2. App installieren bzw. Zum Startbildschirm hinzufügen wählen.
